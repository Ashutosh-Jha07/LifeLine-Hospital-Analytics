### &#x20;Project Overview



Lifeline Hospital Analytics is an end-to-end Data Analytics project that analyzes hospital operations using SQL, Python, and Power BI. The project transforms raw healthcare data into meaningful business insights through data cleaning, exploratory data analysis , SQL queries, and interactive dashboards.





### &#x20;Business Problem



Hospitals generate large volumes of patient and financial data every day. Without proper analysis, it becomes difficult to:



\- Monitor patient admissions

\- Track hospital revenue

\- Analyze doctor performance

\- Understand diagnosis trends

\- Optimize bed occupancy

\- Evaluate insurance claims

\- Improve patient satisfaction



This project provides actionable insights that help hospital management make informed decisions.
